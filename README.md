# ARISTOERUDITOS — локальный запуск

Node.js 22 или новее. Запуск из папки проекта: `npm start`. Остановка: Control+C.

Токен хранится в локальном .env, который исключён через .gitignore. На Render задайте BOT_TOKEN в Environment. Для локального запуска скопируйте .env.example в .env и укажите свой токен.
Заявки после проверки клиентом и нажатия «Отправить заявку» поступают на Telegram ID 448855925. Владелец должен сначала открыть этого бота и нажать /start.

Изображения взяты со страницы https://aristoeruditos.gastroand.me/projects.html?lang=ru и сохранены в assets. Папка assets должна находиться рядом с bot.js. Сайты и приложения показываются с изображениями, портфолио — карточками Lexica, Tastio и Marks & Spencer с кнопками переключения. Отображение изображения заменяется текстом при ошибке загрузки. Фотографии повторно отправляются через Telegram file_id после первой успешной загрузки.

Анкеты хранятся в памяти до 24 часов и теряются при перезапуске. Компьютер и терминал должны оставаться включёнными. Имя и аватар бота меняются отдельно через BotFather.

Проверки: синтаксис Node.js; локальные тесты отправки изображений с подменённым Telegram API; проверка заявки, ошибки отправки, повторной попытки и защиты от повторного нажатия. Реальную доставку фотографий и заявок проверьте в Telegram после перезапуска.

Приветствие использует assets/hero.mp4 с первого экрана сайта: MP4 H.264 без звука, около 650 КБ. Бот отправляет его как Telegram-анимацию с меню. При ошибке показывает логотип.
